## 2. Algorithmic Limitations & Disclosures

### 1. Solution Leakage Guard: Semantic Equivalence Limitation
- **Mechanism:** The Leakage Guard evaluates token sequence similarity and normalized AST tree edit distances against reference solutions at threshold $\tau = 0.80$.
- **Known Failure Mode:** Syntactic similarity detection is fundamentally blind to **algorithmically equivalent rewrites**. 
  - For example, replacing a Python `for i, num in enumerate(nums)` loop with an indexed `while idx < len(arr)` loop and using `dict()` instead of `{}` drops the combined similarity score to **~0.54** (well below $\tau = 0.80$).
  - As reported in Section 6.5 and Table 3 of the IEEE Research Paper, **0 out of 8 equivalent rewrites were caught** by syntactic comparison alone.
- **Pedagogical Impact:** A clever or adversarial user can bypass syntactic filtering by restructuring control-flow primitives. Future work will investigate embedding-based semantic similarity and neural code representations (e.g., CodeBERT / GraphCodeBERT).

### 2. AST Static Time-Complexity Heuristic: Non-Linear Abstention
- **Mechanism:** The complexity analyzer evaluates loop nesting depth (v0) and pattern-matches halving loops, sorting calls, and recursion branching (v1).
- **Known Failure Mode:** Static AST analysis cannot evaluate runtime input-dependent loop boundaries, amortization (e.g., disjoint-set union-find with path compression), or complex divide-and-conquer recurrences without symbolic execution.
- **Architectural Safeguard:** The heuristic is explicitly designed to **abstain** (`ABSTAIN`, confidence `0.0`) when hidden-cost operations (e.g., slicing in loops `arr[i:i+k]`, list membership `x in list`, builtin `sum()`) are detected. This prevents serving misleading complexity bounds.

### 3. Topic Mastery Formula: Pedagogical Heuristic vs Psychometric Measure
- **Formula:** $M' = \text{clamp}(M + 8R - 2H + 3E - T, 0, 100)$
- **Known Anomaly 1 (Hint Degradation):** A learner who produces an optimal solve ($R=1, E=1, T=0$) with $\ge 6$ hints receives a net negative mastery delta (e.g., at $H=6$, $\Delta M = +8 - 2(6) + 3 = -1$; at $H=10$, $\Delta M = -9$). While intentional to discourage brute-forcing hint buttons, it can penalize diligent learners who study all graduated hints.
- **Known Anomaly 2 (Ungated Efficiency):** On failed attempts ($R=-1$), crediting efficiency ($E=1$) produces a delta of $-8 + 3 = -5$ rather than $-8$. A configuration flag `gated_efficiency=True` is provided to disable $E$ when $R=-1$.
- **Scientific Limitation:** Mastery score $M$ is a deterministic engineering heuristic for curriculum sequencing. It is **not** a psychometrically validated measure of latent human cognitive ability (such as Item Response Theory or Bayesian Knowledge Tracing).

### 4. Predictive Solve Probability: Cold-Start Logistic Prior
- **Current Deployment State:** In compliance with anti-fabrication rules, the live platform strictly uses the **closed-form rule-based fallback equation** from Progress Report 02 Section 2.5:
  $$z = 0.045 S_{user} + 0.050 M_{topic} + 1.200 F_{pattern} - 1.600 D_{problem} - 0.0008 T_{sec} - 0.350 H - 0.060 \text{days} - 1.200$$
  $$P(\text{solve}) = \frac{1}{1 + e^{-z}}$$
- **Limitation:** The supervised machine learning classifiers (Logistic Regression, Random Forest, GBDT) reported in early drafts were trained on synthetic telemetry generated by `ml/data/generate_dataset.py`. They are held offline until empirical data is gathered from live human student pilots.

## 3. Infrastructure & Deployment Limitations

### 5. Sandboxed Code Execution Isolation
- Untrusted user code is dispatched exclusively to an isolated **Judge0** REST container.
- If the Judge0 container is offline or unconfigured, the application server returns an honest "Sandbox Offline" notice. **The system will never fall back to local shell execution.**
- Full production deployment requires a running Judge0 instance with Docker privileged cgroups v2.

### 6. External LLM Provider Fallbacks
- The Socratic hint generator supports Anthropic Claude (primary) and OpenAI (fallback).
- When external API credentials are not supplied, the platform automatically serves the curated **Demonstration Hint Bank**. The system never pretends that an external LLM response was generated when operating in offline mode.
